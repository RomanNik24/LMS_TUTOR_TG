# Схема базы данных: MY_LMS

Этот документ описывает реляционную структуру базы данных для проекта MY_LMS. Схема предназначена для управления пользователями, расписанием занятий, учебными материалами и отслеживанием успеваемости.

## 1. Таблица Users (Пользователи)
Центральное хранилище для всех авторизованных пользователей в системе.
- **id**: Primary Key (Integer/UUID).
- **role**: Enum (admin, student). Определяет уровень доступа (администратор или ученик).
- **telegram_id**: Integer (Nullable). Хранит уникальный ID пользователя в Telegram, заполняется при первой успешной авторизации.
- **login**: String (Unique). Основное имя пользователя для входа в систему.
- **password_hash**: String. Хэш пароля пользователя.
- **balance**: Integer. Количество оставшихся оплаченных занятий.
- **lesson_price**: Integer. Индивидуальная стоимость одного занятия для конкретного ученика.

## 2. Таблица Lessons (Занятия)
Управляет расписанием и статусами образовательных сессий.
- **id**: Primary Key (Integer/UUID).
- **student_id**: Foreign Key. Ссылка на id в таблице Users.
- **subject**: String. Учебный предмет (например, математика или информатика).
- **start_time**: Datetime. Время начала занятия.
- **end_time**: Datetime. Время окончания занятия.
- **status**: Enum (scheduled, completed, cancelled). Текущий жизненный цикл занятия.
*Архитектурная заметка:* Эта таблица спроектирована в первую очередь для индивидуальных занятий (один на один), но схема позволяет в будущем расширить её для групп или пар, изменив `student_id` на промежуточную таблицу связи "многие-ко-многим".

## 3. Таблица Homeworks (Домашние задания)
Управление выдачей и отслеживанием самостоятельной работы.
- **id**: Primary Key (Integer/UUID).
- **lesson_id**: Foreign Key. Ссылка на id в таблице Lessons.
- **description**: Text. Подробные инструкции или требования к заданию.
- **deadline**: Datetime. Крайний срок сдачи (дедлайн).
- **status**: Enum (pending, submitted, graded). Указывает на текущий этап задания.
- **student_file_url**: String (Nullable). Ссылка на загруженный учеником файл с решением (например, ссылка на S3).
- **score**: String. Поддерживает гибкие форматы оценок, включая дробные (например, "26/27") или текстовые результаты (например, "Зачет/Незачет").

## 4. Таблица MockExams (Пробные экзамены)
Хранит результаты пробных экзаменов для мониторинга прогресса учеников.
- **id**: Primary Key (Integer/UUID).
- **student_id**: Foreign Key. Ссылка на id в таблице Users.
- **date**: Date. Дата проведения экзамена.
- **subject**: String. Конкретная дисциплина.
- **primary_score**: Integer. Первичный (сырой) балл (например, макс. 21 для информатики, 31 для математики).
- **grade**: Integer. Оценка по 5-балльной шкале, конвертированная из первичного балла.

### Логика конвертации баллов
Поле `grade` вычисляется на основе специфичных для предмета порогов, применяемых к `primary_score`. Пример для ОГЭ по информатике:
- **Оценка 5**: 17–21 балл.
- **Оценка 4**: 12–16 баллов.
- **Оценка 3**: 5–11 баллов.
- **Оценка 2**: 0–4 балла.
