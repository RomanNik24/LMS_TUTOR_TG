# Технологический стек и инфраструктура: MY_LMS

Этот документ жестко фиксирует стек технологий для ИИ-агентов. При написании кода агенты должны строго придерживаться указанных библиотек и инструментов.

## 1. Язык и основные фреймворки
- **Язык программирования:** Python 3.11+
- **Telegram Bot API:** Aiogram 3.x (асинхронная работа, использование Webhooks).
- **Web API Layer:** FastAPI + Uvicorn (для обработки вебхуков и предоставления API для фронтенда).
- **Фронтенд (Mini Apps):** Flet (создание UI для Student App и Admin App на чистом Python).

## 2. Базы данных и хранилище
- **Основная БД:** PostgreSQL.
- **ORM и Миграции:** SQLAlchemy 2.0 (строго асинхронный синтаксис) + Alembic.
- **Кеширование и FSM:** Redis (хранение состояний бота, кеширование расписания).
- **Файловое хранилище:** S3 Object Storage (для хранения изображений/файлов домашних заданий, чтобы не засорять диск сервера).

## 3. Фоновые задачи и уведомления
- **Очереди задач (Task Queue):** TaskIQ или Arq (на базе Redis).
  - *Цель:* Планирование отложенных задач (отправка push-уведомлений за 30 минут до урока и за 24 часа до дедлайна ДЗ).

## 4. Инструменты разработки (DevTools)
- **Пакетный менеджер:** Poetry (строгое управление зависимостями через `pyproject.toml`).
- **Линтеры и форматеры:** Ruff, MyPy (строгая статическая типизация обязательна).
- **Мониторинг ошибок:** Sentry (интеграция в FastAPI и Aiogram для отслеживания сбоев).

## 5. Инфраструктура и Деплой (CI/CD)
- **Контейнеризация:** Docker + Docker Compose. Все компоненты (Бот, FastAPI, Flet-сервер, PostgreSQL, Redis) запускаются в изолированных контейнерах.
- **Веб-сервер / Reverse Proxy:** Nginx (проксирование запросов к FastAPI и Flet, терминация SSL).
- **Хостинг:** Виртуальный выделенный сервер (VPS) на базе ОС Ubuntu.
- **CI/CD:** GitHub Actions. При пуше в ветку `main` запускается пайплайн: проверка линтерами -> сборка Docker-образов -> деплой на VPS по SSH.
