# Описание проекта: MY_LMS (Telegram Bot & Mini Apps)

## 1. Основная концепция и бизнес-логика
**MY_LMS** — это экосистема на базе Telegram-бота для автоматизации работы частного преподавателя (репетитора). 
Главная цель системы — избавить преподавателя от рутины, централизовать учебный процесс и предоставить удобные инструменты аналитики. 

Бот выступает в роли единого окна:
- **Для ученика:** просмотр расписания, сдача домашних заданий, отслеживание своего прогресса (оценки, баллы за пробники).
- **Для преподавателя:** контроль выполнения ДЗ, учет финансов, анализ успеваемости учеников и управление расписанием.

## 2. Роли пользователей
В системе предусмотрено три уровня доступа:

1. **Гость (Не авторизованный пользователь):**
   - Доступ только к чат-интерфейсу бота.
   - Может просматривать «Каталог курсов» / «Услуги преподавателя» (витрина для привлечения новых учеников).

2. **Ученик (Авторизованный пользователь):**
   - Имеет доступ к **Student Mini App**.
   - Не имеет доступа к финансовой информации (оплатам).

3. **Администратор (Преподаватель):**
   - Имеет полный доступ к **Admin Mini App**.
   - Управляет расписанием, заданиями, статистикой и финансами.

## 3. Механизм аутентификации
- Авторизация учеников и администратора происходит через связку **Логин + Пароль**. 
- Это сделано для того, чтобы не зависеть от изменения Telegram ID пользователя (при смене аккаунта ученик сможет просто залогиниться заново в новом боте).

## 4. Основной функционал (MVP)

### 4.1. Зона Ученика (Student Mini App)
Доступна только авторизованным ученикам. Состоит из трех основных модулей:
- **Модуль Расписания (Только просмотр):** Календарь/список занятий. В карточке каждого занятия содержится:
  - Информация о привязанном домашнем задании.
  - Ссылка на видеоконференцию (Яндекс Телемост).
  - Ссылка на онлайн-доску.
- **Модуль Домашних Заданий (ДЗ):**
  - Возможность загрузить файлы (фотографии решений) напрямую в Mini App.
  - Кнопка «Сделал» для заданий, выполняемых устно или на сторонних платформах (например, Stepik).
- **Модуль Отчетов:**
  - Визуализация прогресса: графики среднего балла за ДЗ и динамика баллов за пробные экзамены.

### 4.2. Панель управления преподавателя (Admin Mini App)
Доступна только Администратору.
- **Управление системой (CRUD-операции):**
  - **Управление учениками:** Создание профилей новых учеников, генерация логинов/паролей.
  - **Управление тарифами:** Установка индивидуальной стоимости занятия (ценника) для каждого ученика.
  - **Управление расписанием:** Создание, отмена, перенос уроков, формирование сетки расписания для всех учеников.
  - **Управление ДЗ и пробниками:** Выдача заданий конкретным ученикам или группам, ввод результатов (баллов) за пробные экзамены.
- **Главный Дашборд (Сводка на день):**
  1. Расписание занятий на сегодня.
  2. Список учеников, которые не сдали ДЗ к сегодняшнему уроку.
  3. Список «Должников» (ученики, у которых баланс оплаченных занятий равен нулю или отрицательный).
- **Статистика и Финансы (Только для внутреннего учета):**
  - Подсчет заработанных средств за период.
  - Статистика отмененных занятий.
  - Ведение баланса занятий каждого ученика (уменьшается при проведении урока). 
  - *Примечание:* функционал приема платежей внутри бота не реализуется, учет ведется вручную администратором.

## 5. Система Push-уведомлений (через бота)
Бот должен автоматически рассылать сервисные сообщения ученикам:
- **Напоминание об уроке:** Отправляется за **30 минут** до начала занятия.
- **Напоминание о дедлайне ДЗ:** Отправляется за **24 часа** до окончания срока сдачи, **только если** статус задания не отмечен как «Сдано».
