# Архитектура и структура проекта: MY_LMS

Этот документ описывает архитектурный паттерн и файловую структуру монорепозитория. ИИ-агенты обязаны строго следовать этому распределению логики при написании кода.

## 1. Архитектурный паттерн (API-First & Layered Architecture)
Проект строится по слоистой архитектуре. 
- **Ядро системы:** FastAPI. Он содержит всю бизнес-логику и является единственным компонентом, который напрямую общается с базой данных (через слой репозиториев).
- **Клиенты ядра:** 
  1. Telegram-бот (Aiogram) обращается к сервисам/API для обработки команд в чате.
  2. Фронтенд Mini Apps (Flet) обращается к API FastAPI для отображения данных в браузере.
- **Изоляция:** Запрещается писать прямые запросы к БД (SQLAlchemy) внутри хэндлеров бота или интерфейсов Flet. Вся работа с данными идет строго через вызов методов из папки `repositories`.

## 2. Структура монорепозитория
Проект использует следующую структуру директорий:

my_lms/
├── .github/workflows/     # CI/CD пайплайны (GitHub Actions)
├── src/                   # Исходный код проекта
│   ├── api/               # Роутеры и эндпоинты FastAPI
│   ├── bot/               # Логика Aiogram (хэндлеры, фильтры, клавиатуры, стейты)
│   ├── webapp/            # Логика Flet (UI для Student App и Admin App)
│   ├── db/                # Модели SQLAlchemy и миграции Alembic
│   ├── repositories/      # Паттерн Репозиторий (CRUD операции к БД)
│   ├── services/          # Бизнес-логика (статистика, генерация логинов)
│   ├── core/              # Глобальные настройки (Pydantic Settings, логгер, exceptions)
│   └── worker/            # Фоновые задачи TaskIQ/Arq (уведомления)
├── pyproject.toml         # Зависимости Poetry
├── docker-compose.yml     # Инфраструктура (App, DB, Redis)
├── Dockerfile             # Инструкция сборки образа
└── README.md

## 3. Паттерн Repository
- Для каждой таблицы БД (сущности) должен быть создан свой класс-репозиторий (например, `UserRepository`, `LessonRepository`).
- В этих классах инкапсулируются все операции (SELECT, INSERT, UPDATE, DELETE).
- Это гарантирует, что если схема БД изменится, код придется править только в одном месте.

## 4. Точки входа (Entrypoints)
- Проект запускается через единую точку входа (например, `src/main.py`), которая инициализирует FastAPI, запускает lifespan-события (включая запуск поллинга/вебхуков Aiogram) и подключает Flet-приложение.
