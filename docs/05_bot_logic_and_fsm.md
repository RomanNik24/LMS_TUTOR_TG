# Логика бота и стейт-машины (FSM): MY_LMS

В данном документе описывается архитектура взаимодействия пользователя с Telegram-ботом в рамках проекта MY_LMS. Бот служит основным интерфейсом для уведомлений и точкой входа в экосистему Mini Apps.

## 1. Команды бота (Commands)
Бот поддерживает стандартный набор команд, поведение которых динамически меняется в зависимости от статуса авторизации пользователя.
- `/start` — Запуск и инициализация бота.
    - **Гость:** Выводится приветственное сообщение с предложением авторизоваться через команду `/login` или ознакомиться с доступными курсами через кнопку «Каталог курсов».
    - **Авторизованный пользователь:** Бот распознает `telegram_id`, приветствует пользователя по имени и открывает персонализированное главное меню.
- `/login` — Инициация процесса аутентификации. Запускает соответствующую цепочку состояний FSM.
- `/logout` — Прекращение сессии. Удаляет привязку текущего `telegram_id` из таблицы Users в базе данных. После выполнения команды пользователь переходит в статус гостя.
- `/app` — Вызов специализированной кнопки для запуска Mini App. Ссылка в кнопке формируется на основе роли пользователя:
    - Студенты направляются в **Student App**.
    - Администраторы направляются в **Admin App**.

## 2. Конечные автоматы (FSM)
Для управления сложными сценариями диалога используется механизм Finite State Machine.

### FSM: Аутентификация (Login)
Данный процесс обеспечивает безопасную связку Telegram-аккаунта с существующим профилем в системе LMS.
- `State 1: wait_for_login` — Бот отправляет запрос на ввод логина. Ожидается текстовое сообщение.
- `State 2: wait_for_password` — Бот запрашивает пароль от учетной записи. Ожидается текстовое сообщение.
*Системное действие:* После получения пароля бот инициирует проверку учетных данных в базе данных. При успешной валидации происходит обновление поля `telegram_id` в таблице Users. Если данные неверны, FSM сбрасывается или возвращает пользователя на первый этап.

## 3. Клавиатуры (Keyboards)
Интерфейс бота разделен на постоянные элементы управления и контекстные кнопки.

### Главное меню (ReplyKeyboard)
Основная клавиатура, доступная авторизованным пользователям:
- **Открыть приложение:** Кнопка типа `web_app`, открывающая интерфейс на базе Flet.
- **Мои услуги:** (Для гостей) Быстрый доступ к списку доступных образовательных продуктов.

### Инлайн-кнопки (InlineKeyboard)
Используются для точечного взаимодействия и навигации:
- **Каталог курсов:** Позволяет пролистывать доступные предложения до момента входа в аккаунт.
- **Навигация:** Кнопки «Назад», «Подробнее», «Купить», интегрированные в сообщения с описанием услуг.

## 4. Уведомления (TaskIQ/Arq)
Бот выполняет роль транспортного уровня для системы уведомлений.
Логика формирования push-уведомлений интегрирована с фоновыми задачами (TaskIQ/Arq). Бот не инициирует сообщения самостоятельно на основе таймеров внутри своего кода; он лишь принимает данные от воркеров и доставляет их конечному пользователю на основе сохраненного `telegram_id`.
*Основные типы уведомлений:*
- Напоминания о предстоящих занятиях.
- Уведомления о проверке домашних заданий.
- Системные оповещения об обновлении контента курса.
